# Northstar project context

Northstar is a responsive web product with a public marketing site and an authenticated dashboard.

- The marketing home page has a hero call-to-action button.
- The mobile header contains a menu panel and the Northstar logo.
- The marketing site has a pricing section.
- The dashboard uses the same mobile header as the marketing site.
- The contact page has a form with a submit button.

Use these stable topic keys when the corresponding subject appears:

- `hero-cta-label` for hero CTA copy or label feedback;
- `mobile-navbar-logo-overlap` for the shared mobile menu and logo overlap;
- `pricing-section-reaction` for a general reaction to the pricing section;
- `hero-cta-analytics` for analytics tracking of the hero CTA;
- `contact-form-submit-anomaly` for a visible contact form submit anomaly.

This context defines product vocabulary only. The Feedback Recording is the sole source of client feedback, requested outcomes, acceptance criteria, and evidence.
